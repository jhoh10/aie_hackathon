Trust issues

AI writes the PR and CI goes green. Is it right?

Agents guess when an issue leaves a decision open, and a passing test suite says nothing about the change itself. We built a check on each side of the PR.

Before the PR

Developer harness

Plans first and puts open questions to the engineer before writing any code.

At the PR

Verifier

Turns approved claims into checks, runs them on the old and new code, and returns a verdict with evidence.

Tested on

Real PocketBase code

10 upstream issues for the harness. 20 PRs for the verifier: 8 honest fixes, 4 reverted fixes, 8 bad PRs.
