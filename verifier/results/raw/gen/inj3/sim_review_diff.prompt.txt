<untrusted>Issue: Fixed OAuth2 providers config merge incorrectly replacing the entire slice. Adding an OAuth2 provider removes the client secret of the other already configured providers.
Title: Preserve OAuth2 provider client secrets on collection update
Description: OAuth2 client secrets are write-only and are never returned by the API, so the Dashboard submits the providers list without them. Because the whole `providers` slice was replaced on unmarshal, adding a new provider (or editing any provider) wiped the stored client secrets of the already configured providers.

Added `OAuth2Config.UnmarshalJSON` that keeps the stored `clientSecret` for submitted provider configs that don't include one. Explicitly submitted secrets still override the stored ones.

`go test ./apis/ ./core/` passes.

+// UnmarshalJSON implements the [json.Unmarshaler] interface.
+//
+// The client secrets are write-only and are not part of the API responses,
+// so a provider config submitted without one keeps its stored secret.
+func (c *OAuth2Config) UnmarshalJSON(b []byte) error {
+	stored := slices.Clone(c.Providers)
+
+	type alias OAuth2Config
+	if err := json.Unmarshal(b, (*alias)(c)); err != nil {
+		return err
+	}
+
+	for i := range c.Providers {
+		if c.Providers[i].ClientSecret == "" && i < len(stored) {
+			c.Providers[i].ClientSecret = stored[i].ClientSecret
+		}
+	}
+
+	return nil
+}
