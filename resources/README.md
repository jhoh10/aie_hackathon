# Resources

Links, docs and reference material for the hackathon. Anyone can add to it.

| File | What's in it |
| --- | --- |
| [event.md](event.md) | Hackathon logistics, theme, prizes, judges |
| [sponsors.md](sponsors.md) | Sponsor APIs and docs (Meta, Google DeepMind, MongoDB, Subquadratic, Fetch.ai) |

## Adding something

- A link: put it in the file that fits, with one line on why it's useful.
- A new topic: make a new `.md` file here and add a row to the table above.
- PDFs, screenshots, slides: drop them in this folder and link them from a `.md` file so people can find them.
- Never paste API keys or other secrets here. The repo is public.
